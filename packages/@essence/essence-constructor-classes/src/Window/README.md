# Модальные окна (`WIN`)

Тип: `WIN`. Регистрация: `setComponent("WIN", WindowContainer)`. Без `commonDecorator`.

## Вид

### 1. Обычное окно

```
┌───────────────┐
│ Заголовок     │
├───────────────┤
│ Тело модалки  │
│ Поля ввода    │
├───────────────┤
│        Кнопки │
└───────────────┘
```

### 2. Редактирование в таблице (inline)

```
                Светлая тема, кнопки вверху:
Темная тема     ┌──────────────────────┐
кнопки сбоку    │ Кнопки управления    │
                └──────────────────────┘

                Таблица:
┌─────┐         ┌────────┬───────┬───────┬──────────────┐
│  К  │         │ Кнопки │ Заг1  │  Заг2 │    ....      │
│  Н  │         ├────────┼───────┼───────┼──────────────┤
│  О  │         │        │ Поле1 │ Поле2 │    ....      │
│  п  │         ├────────┼───────┼───────┼──────────────┤
│  к  │         │ Edit   │ Текст1│ Текст2│    ....      │
│  и  │         ├────────┼───────┼───────┼──────────────┤
└─────┘         │              .....                    │
                └────────┴───────┴───────┴──────────────┘
```

Inline-окно грида регистрируется отдельно как `INLINE_WINDOW`.

## Отображение

1. По умолчанию окно рисуется поверх страницы (MUI Modal + `UIForm`).
1. Для inline:
    1. контент — как row, рендер в таблицу;
    1. кнопки управления — по теме, вместо кнопок грида.

## Поведение

1. Окно создаётся один раз и на странице показывается одно.
1. Открытие инициирует кнопка (`handler` → `onCreateChildWindowMaster` / `onRowCreateChildWindowMaster` / `onOpenWindow`).
1. При редиректе нужно пометить кнопку, которая отвечает за добавление.

Обработчики стора: `onCloseWindow`, `onCloseWindowSilent`, `onSimpleSaveWindow`, `onSaveFile`. Сохранение обычно делегируется в `mainStore.handlers.onSaveWindow`.
