# @essence-community/eslint-config-react

Общий ESLint 9 (flat config) для Essence: TypeScript, React, hooks, import, jsx-a11y, prettier, compat.

## Использование

```js
import config from "@essence-community/eslint-config-react";

export default [...config];
```

В этом монорепо так подключены корневой `eslint.config.js` и конфиг `constructor-website`.
